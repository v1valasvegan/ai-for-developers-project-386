# Словарь проекта «Окошко»

«Окошко» — сервис записи гостей на встречи с одним владельцем календаря.

**Владелец календаря**:
Единственный заранее заданный организатор встреч, которому принадлежат календарь и типы встреч.

**Гость**:
Человек, выбирающий тип встречи и свободное время для записи к владельцу календаря.
_Избегать_: клиент, пользователь — когда речь именно о записывающемся госте.

**Тип встречи**:
Вариант встречи с собственными названием, описанием и длительностью.
_Избегать_: тип события.

**Код типа встречи**:
Уникальное обозначение типа встречи, которое задаёт владелец календаря. Служит идентификатором типа встречи, в отличие от его отображаемого названия.

**Слот**:
Интервал времени для встречи; его длительность совпадает с длительностью выбранного типа встречи.

**Шаг стартов**:
Интервал между соседними возможными временами начала встречи в расписании. Не равен длительности слота: наличие старта в сетке само по себе не означает, что слот свободен.

**Запись**:
Бронирование гостем конкретного слота выбранного типа встречи у владельца календаря.

**Предстоящая встреча**:
Запись, время начала которой ещё не наступило.

**Текущая встреча**:
Запись, которая уже началась, но ещё не закончилась. В интерфейсе обозначается меткой «Идёт сейчас».

**Окно записи**:
Скользящий период из 14 календарных дней, в пределах которого гость может выбрать слот.
