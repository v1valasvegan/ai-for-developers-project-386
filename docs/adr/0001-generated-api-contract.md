# Единый API-контракт и генерация клиентов и серверных типов

API описывается в `api/main.tsp`: TypeSpec генерирует OpenAPI, из которого получаются TypeScript SDK для React-фронтенда и типы и маршруты для Rust + Axum. Вместо независимых рукописных описаний запросов и ответов на клиенте и сервере используем один контракт, чтобы изменения интерфейса не расходились между частями приложения.

Сгенерированные файлы не редактируются вручную; реализация обработчиков остаётся вне генерируемых каталогов. Цена решения — дополнительные инструменты сборки и зависимость от возможностей генераторов. `mise run check` повторяет генерацию и проверяет отсутствие расхождений.
