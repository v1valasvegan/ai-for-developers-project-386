# Один образ и постоянный том для учебного деплоя

Собранную SPA и API обслуживает один Axum-процесс на `0.0.0.0:PORT`. Это сохраняет SDK на origin страницы, один публичный адрес и один автоматически запускаемый образ. Отдельные Vite-сервер, reverse proxy и frontend-сервис добавили бы второй runtime или координацию процессов без пользы для текущего масштаба. При отсутствии `PORT` нативный запуск сохраняет прежний `BIND_ADDR`.

SQLite остаётся на постоянном `/data` с одной репликой, как принято в ADR0003. Для учебного размещения выбран Railway с volume в пределах доступного бесплатного кредита: Render Free теряет локальную SQLite при restart/spin-down и не поддерживает постоянный диск. Исчерпание кредита, удаление volume и отсутствие резервной копии остаются ограничениями; платный тариф требует отдельного согласия. Размещение и его публичная приёмка фиксируются отдельно от этого решения.

Настройки единственного сервиса и тома задаются через Railway MCP и проверяются по фактическому состоянию. Корневой Dockerfile определяется сборщиком автоматически; healthcheck — `/api/health`, одна реплика и `DATABASE_PATH=/data/okoshko.sqlite3`. Устаревший `railway.toml` не используется: [Config as Code запрещён для новых сервисов и отключается01.12.2026](https://docs.railway.com/infrastructure-as-code#iac-vs-config-as-code). Добавление отдельного IaC SDK и workflow с новыми секретами ради этих настроек сейчас не требуется.

Деплой не добавляет авторизацию. Публичный `/owner` допускается только для синтетических учебных данных, не для настоящих персональных данных гостей.
