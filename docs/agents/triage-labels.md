# Метки разбора задач

Стандартные роли скиллов соответствуют одноимённым меткам GitHub Issues.

| Роль скилла       | Метка в трекере   | Значение                                          |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Требует разбора сопровождающим                    |
| `needs-info`      | `needs-info`      | Недостаточно информации; ожидается ответ автора   |
| `ready-for-agent` | `ready-for-agent` | Полностью описано и готово для реализации агентом |
| `ready-for-human` | `ready-for-human` | Нужна реализация человеком                        |
| `wontfix`         | `wontfix`         | Делать не будем                                   |

При упоминании роли применять метку из второй колонки. Если словарь изменится, обновить эту колонку, сохранив канонические роли в первой.
